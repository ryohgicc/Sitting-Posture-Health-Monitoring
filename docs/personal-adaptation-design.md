# 个人适配试用版

用户已确认实施。摄像头仍由用户手动开启；个人适配是数值校准，不训练模型、不确定医学极限。

流程：舒适有支撑的参考姿势稳定10秒 → 自然低头、向一侧偏、向另一侧偏、轻微肩线变化，各在用户认为应提醒的位置稳定2秒并确认 → 使用建议线体验实际持续时间和恢复 → 太敏感/合适/不敏感调整 → 明确确认后应用。

只有确认才写入参考姿势和每项阈值；取消保留原设置。未测或信号不可靠的项目明确保留默认线。动作自然、不憋气、不忍痛、不做最大幅度。阈值以稳定变化中位数估算，排除静止抖动；建议范围为默认线的0.6–1.4倍，调整范围0.5–1.8倍。左右偏斜需两侧方向相反，使用较小偏移。缺失/间断清除当前采样，45秒不合格参考提示重试；超过3秒无有效目标或目标更换终止引导，保留已有设置，重新锁定原有规则照常失效旧参考。

只保存最终参考/阈值标量及版本号，不保存动作采样历史。正式通知在整个引导期间屏蔽，体验只显示状态。修改设置、睡眠、锁屏、暂停、停止、重新校准/锁定都中止草稿。初次使用展示入口，设置可重新进入。
