# 减少不必要的后台计算

用户授权尝试性能优化。保留640×480采集、最多5Hz分析、全部指标和时序。先用既有截图离线测耗时；不主动开启摄像头、不新增影像文件。

1. 窗口关闭、最小化、完全被遮挡，或切换到设置/验证页时，停止预览分割/模糊和骨架叠加；姿态监测及提醒保持。回来自动恢复，用户预览开关选择保留。窗口可见状态仅瞬时内存。切换可见性递增预览版本并清空旧图，拒绝旧回调。
2. 背景模糊复用同一帧VisionAnalyzer已检测的全部人脸框，避免第二次人脸检测，仍按锁定人脸匹配与其他人脸遮蔽；外部未提供结果时保留独立检测路径。只能复用本帧结果，不缓存上帧遮罩/图像。
3. MediaPipe输入RGBA内存和CGContext按分辨率复用，尺寸变化重建；每次清空/重绘，推理只读当前帧，不保留历史。串行队列规则保持。

替代方案：降低分析频率或分辨率可能影响近距离/多人识别和稳定采样，本轮不采用；更换模型/运行时范围大且无当前证据，不采用。

验收：窗口/标签切换停预览且新帧指标仍判断、隐藏期间无旧图泄漏；重开不自动启用用户关闭的预览；已知人脸框路径不削弱隐私回退；复用缓冲内容/尺寸正确。比较优化前后同一离线数据的耗时，明确不等于实机相机能耗或整体CPU降幅。真实长时实测仍待用户。
