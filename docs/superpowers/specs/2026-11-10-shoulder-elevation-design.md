# 清晰命名与双肩抬高检测

用户请求改名，并基于刚才双侧耸肩讨论增加检测。实施解释：保留双肩高低差，新增“双肩抬高（试用）”，不替换旧指标。

名称：lean原始编码保留，显示“头肩横向偏移”；shoulders编码保留，显示“双肩高低差”（仍按连线角度相对参考变化测量）。新增shrug编码，显示“双肩抬高”。

方案：复用已锁定同一MediaPipe骨架的双耳(7/8)、肩(11/12)，像素空间计算每侧肩耳垂直间距并除双肩横向间距（避免单侧抬高拉长斜线导致另一侧比例缩小）。相对舒适参考取两侧缩短量的较小值，只有两侧同时缩短才累计。工程默认提醒线8%肩宽，沿用持续时间默认5秒、恢复55%/3秒、独立开关及个人适配。不新增模型、网络、图像保存。缺少任一耳/肩、几何不合理、头部转动明显则不判断。肩耳缩短也可能来自头部位移，因此明确是估计提醒，不宣称辨认肌肉紧张或圆肩。

替代方案：用肩膀绝对画面高度会受整体位移影响；只用肩线角度无法识别双侧同高抬起。采用双侧归一化肩耳距离，复用现有本机推理。

兼容：新增可选标量字段，旧baseline/profile JSON可读；旧校准无双耳数据则新项目等待重新校准。enabled.v1旧用户保留原三个开关，新增项默认开启，独立版本标记保证用户关闭后不被重新开启。个人适配增加自然轻抬双肩步骤，可跳过；取消不覆盖已存数值。

验收：双侧同高抬肩产生shrug事件且肩线不变；单侧不产生shrug；整体平移/缩放不改变距离比例；耳缺失/头部转动清空该指标计时；旧存储可读；校准、适配、UI与提醒使用一致单位/方向。真实摄像头识别效果待用户试用。
