# 坐姿搭子 · PosturePal

在当前 Mac 上运行的本地坐姿提醒验证版。通过内置摄像头、Apple Vision 头姿和 MediaPipe 肩部模型分析头部俯仰、头肩横向偏移、双肩高低差与双肩抬高，支持个人校准、菜单栏常驻、无声系统通知和独立活动提醒。

**当前状态：可构建、可启动的验证版，尚未通过真实坐姿准确率和60分钟能耗验收。** 不诊断圆肩、颈椎问题或疼痛原因。

## 打开与使用

1. 双击 `dist/坐姿搭子.app`；启动不会自动开启摄像头。菜单栏图标可重新打开状态窗口。
2. 点击“开启监测”，阅读说明并允许摄像头。显示头部和双肩，保持正面、正常光线。
3. 绿色框标出锁定目标，背景同事不会导致整帧停用；选错时点预览中自己的脸或点“重新锁定我”。目标丢失超过2秒需手动重锁，重锁后需重新校准。点击“校准 / 重新校准”，舒适稳定地保持约10秒。不要刻意夹肩或挺胸。未获得基线的指标显示不可判断。
4. 预览下方有“背景模糊（应用内）”开关，选择自动保存，首次默认开启。使用系统摄像头效果时可关闭；关闭会跳过应用分割、显示摄像头提供的画面，无需重新校准。开启时，只保留锁定目标的人物轮廓。未锁定或分割失败时全幅模糊/留空，不切回原始画面。其他检出人脸额外遮蔽；人物重叠/遮挡仍可能有误差，不能保证匿名化。隐藏预览会停止模糊处理，坐姿监测继续。
5. 在“验证与限制”页完成试用：正常办公至少5分钟看可用率，再分别测试四项变化。默认姿态验证模式只显示事件，不发送姿态纠正通知。
6. 试用后可点击“我已试用，启用姿态系统通知”，并允许系统通知；此操作不表示完整产品验收通过。实际方向、误报和摄像头效果仍需核对。
7. 关闭设置窗口后继续工作。可在菜单栏停止或退出。

预览中的肩部绿线是模型估计，已加显示防抖；小幅晃动不表示姿势异常。显示防抖不改变校准、指标和提醒阈值。截图中的“等待校准”表示尚未建立参考姿势。

双肩抬高需双耳、双肩清晰入镜，正面且头部稳定。旧校准没有肩耳参考，升级后请重新校准或重新做个人适配；新项默认开启，可单独关闭，原三项开关保留。低头、转头、歪头明显或耳朵缺失时，只暂停新项判断并清空它的计时。肩耳距离也可能受头部上下移动影响，不能据此确认肌肉紧张、圆肩或病理性耸肩；工程默认8%仍需实际试用验证。

活动提醒默认开启，每45分钟一次，与摄像头独立。拒绝摄像头权限时仍可使用。离开画面不算完成活动，请用“我已活动”重置。

## 个人适配（0.7.0 试用）

开启监测、确认绿色目标框后，在状态页点“开始个人适配”，或在设置中点“重新进行个人适配”：

1. 用舒适、有支撑的参考姿势稳定10秒，估计基准和静止抖动。
2. 自然低头、向一侧偏、向另一侧偏、改变双肩高低，再轻轻同时抬起双肩，各在**你希望提醒的位置**保持2秒并点记录。不是最大活动范围测试，不适请停止。看不清或不想测可跳过，左右任一侧跳过会保留整个左右项目默认线。
3. 体验实时100%提醒线：严格超线并持续所设时间（默认5秒）形成事件；回到55%以内稳定3秒恢复。此阶段不会发送姿态纠正通知。可逐项点“太敏感 / 不够敏感”调整15%，调整会清空试用计时。引导期间活动提醒也暂停。
4. 点“合适，查看并确认”，再点“确认应用个人参考和提醒线”。取消保留旧设置，确认才保存数值。关闭窗口后引导继续，可从菜单栏重新打开。

这是一轮数值校准，不重新训练模型，也不会随你平时的姿势静默改变标准。建议线限于默认工程线的0.6–1.4倍，手动调整限0.5–1.8倍；这些是防止异常样本产生极端设置的工程护栏，并非医学范围。跳过项保持默认值，无可靠参考的项仍不参与判断。灵敏度继续在个人线基础上生效。参考不稳定或动作和噪声分不开时会提示重试。

停止、暂停、锁屏、休眠、目标更换、画面中断或超过3秒无可用目标，以及修改设置都会取消未确认草稿。普通重新校准成功后、重新锁定或清除校准会清除个人阈值；移动屏幕或椅子后请重新适配。只保存最终参考和阈值，临时数值采样在结束时丢弃，无动作历史。

## 看懂提醒线

四项都是**相对你校准参考的估计变化**，不是疾病/疼痛或损伤边界。当前工程默认值（标准灵敏度）：

| 指标 | 进入提醒线 | 实际测量 |
|---|---|---|
| 头部向下俯仰 | 约11.5° | 面部角度相对参考向下增加，不是颈椎角度 |
| 头肩横向偏移 | 18%肩宽 | 鼻子相对双肩中点的横向比例变化，不是躯干角度 |
| 双肩高低差 | 约8.0° | 画面双肩连线角度相对参考变化，不评价圆肩 |
| 双肩抬高（试用） |8%肩宽 | 两侧肩耳垂直间距相对参考的缩短，按双肩横向间距归一化并取较小变化；单侧抬肩由高低差项目观察 |

未适配时，高灵敏度为上述数值×0.7，低灵敏度×1.4；适配后以个人数值为基础，设置页实时列出具体数值。主页显示当前变化/提醒线/占比，竖线标出100%；80%起显示“接近提醒线”，仅用于观察。**严格超过100%并持续所选时长**才进入偏离事件，默认5秒；恰好100%不启动计时。计时来自实际判断状态，而不是UI推算。设置 → 姿态提醒 → 持续偏离可输入1–120秒整数，也可加减或点“设为5秒”；自动保存，修改后重新计时。已有保存值保留，首次默认5秒。

事件形成后须回到进入提醒线55%以内并稳定3秒才消退（标准约6.3°、9.9%肩宽、4.4°），避免边界来回跳变。验证模式只显示事件；静默不累计偏离；通知仍受冷却、合并和系统设置影响。画面/指标缺失时不显示“正常”，而是不可判断。

先用舒适、有支撑的姿势校准；不要刻意挺胸夹肩。校准本身不证明该姿势健康。经常改变姿势，指标未超线也不必保持不动。[OSHA工作姿势指南](https://www.osha.gov/etools/computer-workstations/positions/)提供舒适支撑、肩膀放松等建议，**没有规定我们的11.5°/18%/8°检测阈值**。阈值仍需个人试用与误报验证。

参考 [Open Posture](https://github.com/whatnotbot/open-posture) 的个人基线/持续偏离/恢复反馈和 [posture-check](https://github.com/enkr1/posture-check) 的实时变化与灵敏度调节思路；本次自行实现，没有复制第三方代码。

## 暂停与通知

- 稍后提醒10分钟：仍采集与判断，暂停姿态和活动通知，不补发旧通知。
- 暂停检测30分钟：停止采集并释放摄像头，同时暂停活动计时；到期且会话已解锁时自动恢复。
- 停止检测：摄像头不自动恢复，独立活动提醒仍可继续。
- 锁屏/休眠：停止采集；仅原先请求监测时解锁恢复，不覆盖手动停止。
- 退出：停止全部工作。

姿态变化默认持续5秒后形成事件；恢复需稳定约3秒。同类通知冷却10分钟；不同事件合并且每分钟最多一条。恢复姿态或手动完成活动会取消对应待发旧通知。所有系统通知无声音，尊重专注模式。摄像头中断时清空偏离计时并提供恢复说明。

## 隐私与数据

不上传、不录像、不保存照片或关键点轨迹、不保存历史统计。推理在本机运行，模型和原生运行库随应用附带，使用时无需下载。仅在 UserDefaults 的 `local.posturepal.mac` 域保存设置、数值基线、已确认个人提醒线与试用选择。可以在设置中清除基线及个人阈值；退出后删除应用即可卸载，彻底清除偏好可执行：

```sh
defaults delete local.posturepal.mac
```

应用背景模糊可开关，仅作用于本应用显示；摄像头仍在本机内存中接收完整画面，其他应用的摄像头不受影响。应用没有录像功能。分割会增加处理耗时，隐藏预览可省去这部分开销；尚未测定新版60分钟资源占用。

摄像头开启时系统指示灯会亮，隐藏预览不等于停止摄像头。前景位置锁定不做人脸身份识别，也不能保证识别所有入镜人员。多人贴近、目标交叉、转身、遮挡和暗光可能暂停判断；目标离开后不会自动切到背景同事。头部角度不再依赖骨架是否识别，肩部缺失时相应指标保持不可判断。更换椅子或屏幕角度后请手动重校准。

## 开发与构建

Swift 6 工具链，采用 Swift 5 language mode；macOS 14+ SDK API。当前只验证这台 Apple Silicon Mac 的构建和启动，最低版本声明不等于已测兼容范围。已附带固定版本的 MediaPipe 0.10.32 ARM64 运行库和 Pose Landmarker Lite 模型；无需安装 Python 或 pip。来源和许可见 `Vendor/README.md`。

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift test
swift build -Xswiftc -warnings-as-errors
./scripts/build-app.sh
open dist/坐姿搭子.app
```

打包脚本创建带摄像头用途说明的 `.app` 并做 ad-hoc 签名，无开发者证书签名或公证。重建可能影响系统权限识别；没有关闭系统安全设置或修改全局策略。

## 结构与验证

- `Sources/PostureCore`：几何、校准、姿态状态机、活动计时和通知合并。
- `Sources/PostureVision`：生产相机和离线复现共同使用的 Vision 人脸角度、MediaPipe 肩鼻关键点、前景目标选择与严格关联。
- `Sources/PostureProbe`：离线图片复现工具，不打开相机、不保存图片；`--multi`在内存中合成额外小人脸用于回归，`--require-shoulders`要求原有头/横向/肩线指标可用；`--require-shrug`额外要求双肩抬高输入可用；`--privacy`核对分割、全幅模糊降级和背景细节抑制，不保存图片。
- `Sources/MediaPipeBridge`：固定版本 C ABI 适配器，动态载入随应用提供的本地运行库。
- `Sources/PosturePal`：Vision/AVFoundation 摄像头、原生界面、通知和应用生命周期。
- `Tests/PostureCoreTests`：持续时间、遮挡、采样间隔、冷却、部分校准、方向、计时及会话代际等回归测试。
- `docs/VALIDATION.md`：已验证证据、仍待设备实测的完整验收清单。

没有数据库、迁移或部署。源码托管于 [GitHub](https://github.com/ryohgicc/Sitting-Posture-Health-Monitoring)。版本记录见 CHANGELOG.md。
